# Icon meanings

All UI icons are imported from `src/icons/`, the only lucide-react import site.
Use the same symbol for the same action in buttons, menus, tabs and empty states.
Do not use shortcut letters as tool faces. Charts and editing overlays are drawings,
not icons. Keep their SVG geometry with the feature that owns it.

24 px contextual icon with a title and a hint describing the next step.
Track headers infer their icon from all clips; mixed visual tracks use Film.
Reserved exports used by adjacent feature work stay available.
