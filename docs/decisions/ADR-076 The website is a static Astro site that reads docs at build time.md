# ADR-076: The website is a static Astro site that reads docs at build time

**Date:** 2026-10-18. **Status:** accepted.

## Context

The owner asked for an official site that sells OpenFrame as an open-source
experiment, looks like the app and its launch film, and stays true: no
claim the code does not back, no promised download. It needs a home page,
feature, AI and MCP, experiment, privacy and credits pages, and a real
documentation section whose MCP tool reference never drifts from the app.

Constraints:

- The repository will hold two projects side by side, the app (moving to
  `openframe-application/`) and the site. The site must not import the
  app's source or depend on its layout.
- It is local-first like the app: no analytics, trackers, font CDNs or
  third-party requests.
- It must score well on Lighthouse (performance, accessibility, best
  practices, SEO) and be fully static for GitHub Pages.
- `docs/MCP tools.md` and `docs/Agent playbook.md` are generated by the
  app from its tool definitions, and `npm test` fails when they drift.

## Decision

- **Astro, static output, in `openframe-website/`** with its own
  `package.json`, lockfile and scripts. Astro renders every page to HTML
  at build time and ships no JavaScript unless a component asks for it.
  Astro 7.3.8: 7.4.0 (three days old) needs Node 22.22, and 7.3.8 is the
  newest release that runs on the Node 22.14 the owner's machine has; CI
  uses the latest Node 22.
- **React only for two islands**: the hero film player (the film over its
  own timeline of chapters and music sections, with a live playhead) and
  the MCP tool finder. Copy buttons and the loops' play-on-screen logic are
  a few lines of plain script each. Everything else is static.
- **Plain CSS with tokens** from the app's palette and the film's light
  (`src/styles/global.css`); no Tailwind or UI kit, whose defaults are the
  template look the owner ruled out. Inter is self-hosted from
  `@fontsource-variable/inter`, and its Latin file is preloaded.
- **The docs are read, not copied.** `src/lib/docs.ts` reads `../docs` (or
  `OPENFRAME_DOCS`) with unified, remark and rehype: the user guide,
  keyboard shortcuts, agent playbook and architecture pages render their
  markdown; the MCP reference is split into groups and tools for a page
  with a search island; Obsidian `[[links]]` point at site pages or at the
  files on GitHub. The numbers the site quotes (141 tools, the decision
  count, effect and transition counts, the first day of the history) are
  parsed from the same files.
- **The app's icons, copied.** `scripts/copy-icons.mjs` writes the app's
  Lucide set (`src/icons/index.ts`) as SVG files into the site, so a
  feature has the icon users see in the app, and each feature keeps one
  icon and one hue everywhere (`src/lib/features.ts`).
- **Media are made by scripts and checked by eye.** `make-media.mjs` cuts
  the film and the loops from the agents' recordings (cropped to the
  feature, metadata stripped); `capture.mjs` builds demo projects through
  `window.videoEditor.mcp` and takes screenshots headless with the model
  list stubbed and other hosts blocked.
- **`compressHTML: false`.** Astro 7's compressor dropped the space between
  a word and an inline element starting on the next source line ("the" +
  newline + `<a>roadmap</a>` became "theroadmap"); turning it off costs a
  few kilobytes of whitespace.

## Consequences

- The site cannot say something the docs do not: change Features.md or
  regenerate the MCP guide and the next build follows. Pages written in
  the site (home, features, AI, experiment, privacy) still need a person
  or agent to keep their sentences true; their sources are named in
  `docs/Website.md`.
- The build fails loudly if `../docs` is missing, rather than publishing
  an empty reference.
- `docs/Keyboard shortcuts.md` is written by hand from `src/lib/keymap.ts`;
  a generator test like the MCP guide's would keep it from drifting.
- When the app moves into `openframe-application/`, only the
  build-from-source commands (`src/data/build.ts`) and the icon copy
  command change.
